# Driftwatch mining target list — Indian merchant storefronts.
# One domain per line. Bare domain; scheme/www/path are stripped by the miner.
#
# Four buckets, ~50 domains total:
#
#   1. SMALL/MID D2C (20)      — Instagram-native / Shopify-lite storefronts,
#                                 chosen for likely decent Wayback coverage.
#   2. DRIFT-PRONE (10)        — nutraceutical/supplement D2C, lending-adjacent
#                                 fintech, crypto/trading services. Categories
#                                 where real business-model or trust-posture
#                                 pivots are plausible between t0 and t1.
#   3. STABLE CONTROL (10)     — large, established merchants where drift
#                                 should be minimal. Baseline for the "none"
#                                 class.
#   4. BUFFER (10)             — extra slots, since JS-lazy-load / broken-replay
#                                 failures (see chumbak.com in status.json) eat
#                                 mining slots without producing a pair.
#
# Confidence flags (inline comments): entries marked MODERATE are brands I'm
# fairly but not fully certain of the exact registered domain for — verify
# before treating a hard failure on one of these as a real absence-of-archive
# signal rather than a wrong-domain typo.
